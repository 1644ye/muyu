# 幕予 1.0.0-beta.1

首个 Windows x64 便携预发布版。沿用项目 1.0.0 版本线，使用 beta 标记尚未完成 Wallpaper Engine 实机和全新系统验证的状态。

**推荐下载：`Muyu-1.0.0-beta.1-windows-x64-portable.zip`**。已包含固定版本 Node.js 24.22.0 运行时，普通用户无需安装 Node、安装依赖或编译。`SHA256SUMS.txt` 用于校验下载完整性。GitHub 自动生成的 Source code 附件仅为源码，不是便携成品。

## 启动

完整解压到固定目录，双击“一键打开.bat”，在 Edge/Chrome 中使用本地编辑器。仅发布 Windows x64；建议 Windows 10/11，其他系统和架构未验证。默认地址 `http://127.0.0.1:4173`，需保持本地服务运行。

## 功能与依赖

- 中文可视化编辑、六类模板、素材和图层、撤销重做、工程备份与独立壁纸导出。
- 信息组件、透明/椭圆等样式、CSS/JSON 自定义。
- CPU/内存等本机版壁纸导出自动配置只读连接，并设置当前用户信息服务登录启动；仍依赖随编辑器提供的本机服务。本机版不能直接迁移到另一台电脑。
- 编辑器便携包不能导入 WE；请在编辑器里导出壁纸 ZIP、解压，再将其中 index.html 导入 WE 编辑器，保存并应用。WE 单独安装，真实频谱/媒体接口依赖 WE；网络组件依赖网络与相应 API，私密接口凭据自行配置。

## 数据与升级

作品和二进制素材保存在浏览器同来源 IndexedDB，工程 ZIP 是可靠的手动备份。服务配置/日志位于 `%LOCALAPPDATA%\Muyu\.runtime`，本地 JSON 位于 `%LOCALAPPDATA%\Muyu\data`，不写入程序目录。
升级前备份工程、停止旧编辑器和信息服务，再解压新版。保留浏览器数据和用户数据目录；系统壁纸在新版重新导出一次以更新登录启动路径。没有自动更新器。

## 验证与限制

已完成的测试记录随发布准备更新，见仓库 `release/VALIDATION.md`。本次不宣称 WE 实机、全新电脑、登录重启或安装/卸载程序验证通过。没有安装器，仅便携包；应用未配置代码签名，不声称通过系统信誉认证，也不要求关闭安全防护。

私密代理/本地 JSON 与系统指标混合导出暂不支持；视频编码和 WE 的浏览器实现存在兼容性限制。项目整体尚未指定开源许可证；没有新增开源许可授权。原始示例资源及 Node.js 许可随包保留。
