幕予 1.0.0-beta.1 · Windows x64 便携预发布版

推荐系统：Windows 10/11 64 位（x64）。本次实际验证环境见 Release Notes；不宣称支持 ARM64、32 位、macOS 或 Linux。

首次启动
1. 完整解压 ZIP 到固定目录，例如 D:\Apps\Muyu。不要在压缩包内直接运行。
2. 双击“一键打开.bat”。已内置 Node.js，不需要安装开发环境、npm install 或编译。
3. 默认浏览器打开 http://127.0.0.1:4173。推荐当前版本 Edge/Chrome。
4. 选择模板、导入素材、调整布局，使用“文件 → 导出工程包”备份；“导出壁纸”生成 Wallpaper Engine 用包。

编辑器和壁纸是两种不同产品文件
本便携包是编辑器，通过自带的本地 HTTP 服务运行，不能直接拖入 Wallpaper Engine。
编辑器导出的 wallpaper.zip 才是壁纸交付包：完整解压，在 Wallpaper Engine 编辑器中将 index.html 拖到“创建壁纸”，保存并应用。
Wallpaper Engine 需单独安装/购买，不包含在本包中。下载 ZIP 不等于已安装壁纸。
普通图片、文字、时钟、粒子等导出壁纸不需要编辑器服务。CPU/内存/网卡/电池依赖本机伴随服务。
导出系统信息壁纸时，会自动启动伴随服务并为当前用户设置登录启动；只读授权自动放入本机版壁纸，无需填码。
系统信息壁纸仅绑定导出时的电脑；换电脑需重新导出。请保持本编辑器目录和内置运行时存在。
私密接口/本地 JSON 文件与系统指标混合导出暂不支持。天气、HTTP、RSS 等需要网络及服务许可；私密接口可能需要自备 API 凭据。
真实音频频谱、媒体信息由 WE 接口提供；编辑器模拟音频有标注，不代表真实采集。GPU/温度等未实现指标不伪造数据。

数据、备份和升级
作品及导入素材自动保存在所用浏览器针对 http://127.0.0.1:4173 的 IndexedDB 中。换浏览器/端口、清理网站数据、使用隐私窗口会影响恢复；务必导出 .muyu.zip 作为独立备份。
发布版服务凭据和日志保存在 %LOCALAPPDATA%\Muyu\.runtime；本地 JSON 数据目录为 %LOCALAPPDATA%\Muyu\data。不要公开分享凭据目录或本机自动连接壁纸。
升级前导出工程备份，关闭编辑器标签页，双击旧版本“停止编辑器.bat”和“停止系统信息.bat”，完整解压新版到新目录，再启动并导入备份。不要删除上述用户数据目录。
若使用系统信息壁纸，在新版重新导出一次，以更新服务登录启动路径。浏览器同来源自动保存数据和用户服务配置会保留。
停止编辑器不删除作品。关闭系统信息自动启动使用“关闭系统信息自动启动.bat”；停止当前服务使用“停止系统信息.bat”，两者独立。
不再使用时先关闭自动启动并停止两个服务，再删除解压目录；用户数据不会自动删除。

常见问题
端口冲突：先关闭旧版本的本机服务；不要同时运行多个版本。防火墙或安全软件阻止时按组织策略处理，不建议关闭安全防护。
离线：内置模板、设计、工程导入导出可用；联网组件会显示不可用，不会伪装成真实数据。
视频：WebM/Ogg 支持取决于实际编码和 WE 浏览器；未承诺所有编码兼容。
这是未签名的便携应用，无安装器和自动更新器。没有声称通过 SmartScreen 信誉认证；Node 官方二进制的原有签名不等于整个应用已签名。
项目整体尚未指定开源许可证，见 RIGHTS.md；Node 和示例资源许可见 licenses 文件夹。
本次没有 WE 实机验证、全新 Windows 机器测试或实际注销重登测试，作为 beta 预发布供试用反馈。
