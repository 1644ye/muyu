幕予示例合集

still / landscape / fluid / stars / neon / focus：六套原有可编辑设计模板。
compatibility：包含原创 TTF、图片和 VP9 WebM 的媒体验证工程。
info-demo：一个明确标注的本地 JSON 示例值驱动四种 CPU 展示；包含 CSS 发光与 JSON 阈值。
info-live：真实系统、天气、时钟、月历和便签信息桌面。系统插件需要本机伴随服务与令牌；天气需要网络。

每个目录提供 .muyu.zip 可编辑工程、.wallpaper.zip 壁纸交付包，以及已解压的 wallpaper/。
导入编辑器请用工程 ZIP。Wallpaper Engine 请完整解压壁纸 ZIP，再将 index.html 拖到“创建壁纸”。下载 ZIP 并不等于已安装。
未执行 Wallpaper Engine 实机验证。普通浏览器中没有 WE 媒体接口，系统插件没有本机令牌时明确降级。

user-progress.plugin.json：可导入的声明式插件定义，不执行 JavaScript。
cpu-glow.css：插件局部 CSS 示例。
neon-glow.style.json：可导入的外观与局部 CSS 预设。
mint.theme.json：可导入的全局主题预设。
