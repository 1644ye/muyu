# 本机壁纸自动连接（当前版本）

编辑器中含 CPU、内存、网络、电池等系统数据源的作品，点击导出时自动启动本机伴随服务、设置当前 Windows 用户登录启动，并嵌入仅能读取系统指标的授权。解压后将 index.html 导入 Wallpaper Engine，保存并应用，无需填连接码。旧包需要重新导出并导入一次。

服务仍是必要组成部分：网页壁纸不能自行执行 Windows 采样程序。请保留编辑器目录与 Node 运行环境。服务仅监听 127.0.0.1；包内授权不能停止服务、访问私密代理或本地 JSON 文件。工程包不包含授权。本机版绑定导出时的电脑，换电脑需在目标电脑重新导出。包含私密代理或本地文件与系统指标的混合导出目前会提示不支持，不会偷偷打包管理密钥。

关闭自动启动：双击根目录“关闭系统信息自动启动.bat”。仅停止当前服务：双击“停止系统信息.bat”。这两项互相独立。再次导出本机系统壁纸会重新启用登录启动。

## 旧包手动连接（仅作兼容）

# Wallpaper Engine 显示 —%：连接系统信息

`—%` 与“需连接本地伴随服务”表示没有系统信息连接。导出的壁纸有单独的运行环境，不能读取编辑器 IndexedDB 中的私密连接；工程和 ZIP 也不会带入本机令牌。

1. 双击根目录 **连接桌面系统信息.bat**。
2. 在打开的页面点击“启动服务并复制连接码”。页面会实际请求 CPU/内存，成功后复制原始令牌，兼容已有壁纸。
3. 打开 Wallpaper Engine，选中当前壁纸，在右侧属性的 **本机信息服务令牌** 或 **本机系统信息连接码** 中按 Ctrl+V，按 Enter 或点击输入框外确认。
4. 等待数秒。服务保持运行，CPU/内存应恢复实际数值。下次启动电脑后需再次启动服务；没有擅自设置开机启动。

已有输入项时无需为了填写连接码重新导入。新版本支持带本机地址的 JSON 连接码；向导高级设置可复制，用于自定义端口，旧壁纸只支持原始令牌。

## 诊断

| 表现 | 检查 |
| --- | --- |
| 需连接 / 未填写连接码 | WE 当前作品未配置 `companiontoken`，或改了另一张壁纸 |
| HTTP 401 / 无效连接码 | 服务更换过令牌、粘贴了错误内容；从向导重新复制 |
| 网络 / CORS / 服务不可达 | 先重新启动本机服务；检查地址、端口和许可来源，勿关闭认证来解决 |
| 台式机电池不可用 | 系统没有电池或未提供此字段；CPU/内存不受影响 |
| 有数值但样式仍是旧版 | 原壁纸目录保留的是旧运行代码；修改编辑器后需要重新导出、导入 |

若没有输入项：导入网页时 WE 会生成项目配置。使用 WE 编辑器的项目设置添加“文本输入”属性，**内部键名为 `companiontoken`**，然后保存并应用。也可关闭该项目编辑器，先备份 WE 的 `project.json`，再合并导出包中的 `general.properties`；保留 WE 生成的其他元数据。不要整份覆盖原文件。

官方流程：[创建网页壁纸](https://docs.wallpaperengine.io/en/web/first/gettingstarted.html)、[用户属性](https://docs.wallpaperengine.io/en/web/customization/properties.html)。

2026-10-18 的只读诊断：当前机器的 Wallpaper Engine 和本机服务都在运行；当前壁纸有令牌输入项，但 WE 已保存配置中没有发现该壁纸的令牌记录。本机服务在携带本机令牌及 `Origin:null` 时返回 200。没有修改 WE 配置或用户作品，没有把本机令牌写入报告。浏览器连接测试与回调模拟不能证明 WE 已收到设置，请以桌面实际数值为准。
