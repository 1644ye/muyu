# 样式自定义与复核记录

2026-10-18。本轮针对透明背景、椭圆、预设名与实际效果不一致的问题，重新检查模型、控件、15 种展示、10 个预设、CSS、历史、资源替换和导出。测试使用独立工程，没有替换浏览器中的原作品。

## 直接制作

双击根目录 `一键打开.bat`，已有页面请刷新。选中信息插件，在右侧向下找到“样式与形状”。

- **完全透明 · 仅保留内容**：清除底板渐变、背景模糊、边框及阴影，保留文字与图表原来的透明度。也可以单独设置“背景不透明度 %”；顶部图层“透明度”仍影响整个组件。
- **轮廓形状**：矩形、圆角、椭圆、胶囊。椭圆跟随图层宽高；“设为正圆并锁定比例”统一宽高。圆角可以分别设水平和垂直半径，清空后继承统一圆角/主题。
- **背景与装饰**：拾色器或 CSS 颜色（例如 `transparent`、`#13251f80`、`rgba(0,0,0,.2)`、主题变量），渐变、背景透明度、边框样式、模糊、阴影颜色/方向/模糊均可调。
- **图表外观**：前景、轨道颜色/透明度、线宽、条高。分段另有数量、间距、圆角、横纵方向和逐段渐变高光；0% 无激活格，100% 全激活，其他值向下取整。
- **字体与动效**：字号、字重、行高、负字距、本地字体、排版、间距、图标、周期、过渡和缓动。环形与仪表的数字也使用所填字号。

可视化样式之后仍会叠加全局 CSS、局部 CSS 和动态规则。控件已明确提示这一关系；需要排查自定义覆盖时点“停用本插件 CSS 覆盖”，代码会保留。全局 CSS 可在画布设置中关闭；规则通过“插件 JSON / 动态规则”管理。输入不完整/非法 CSS 时，控件显示“未应用”，保留上一份有效场景，修正即可继续。

## 预设实际行为

| 预设 | 实际表现 |
| --- | --- |
| 极简透明 | 无底板、无模糊、无边框、无阴影 |
| 玻璃卡片 | 半透明底色、背景模糊、细边框 |
| 仪表盘 | 自动切为弧形仪表与指针 |
| 环形进度 | 自动切为环形进度图 |
| 分段进度条 | 自动切为独立格子组成的分段进度 |
| 终端风格 | 等宽字体、绿色、终端提示符、直角外框 |
| 像素风格 | 原创内嵌像素数字字体、硬边框、阶梯过渡；中文采用系统回退 |
| 霓虹风格 | 紫色、数字发光与外部光晕 |
| 信息面板 | 深色不透明面板与分层文字 |
| 液体填充 | 自动切为按数值涨落的液面，带波动动画 |

切换预设会完整重置外观，清理上个预设的渐变、模糊、发光、字体和轮廓。数据源、字段和功能设置保留；仪表/环形/分段/液体需要数值字段。其他外观不强制改变已有展示。数据类型与展示不匹配时给出提示，不再空白或伪造 0；数据不可用时保留真实来源状态。

“保存此样式”同时保存展示组件、外观、排版和 CSS，下载 JSON 备份。旧样式没有展示字段时继续保留当前展示。工程仍为 v2，旧工程自动补全新增默认项，无需手动编辑 JSON。

## 本轮修复

1. 清空背景生成空 `--bg` 引发校验错误；现在规范为 `transparent`，空渐变合法。
2. 预设仅换部分颜色、语义图表不切换、上一预设效果残留。
3. 分段条只像普通进度条、轨道覆盖激活色、阴影 0 仍有残影。
4. 背景透明度与内容透明度混在一起；透明底板仍存在背景模糊。
5. 环形数字字号被固定值覆盖；水平/垂直圆角缺少控件。
6. 切到没有单位的字段仍残留百分号和倍率。
7. 素材替换遗漏 CSS、规则、主题及个人样式中的标记资源引用。
8. 禁用的局部 CSS 动画仍导出速度选项，全局 CSS 动画反而遗漏；原生全局动画暂停/恢复未统一处理。
9. 导出缩略图将所有插件画成固定绿色方卡片；现在按实际 DOM 样式捕获透明、轮廓、文字与图表。
10. 零数量/零强度粒子仍持续调度；无效的即时样式输入可能先污染场景。

原生形状另增加独立“填充不透明度”，设 0 可只保留描边；原生圆形/椭圆使用宽高决定轮廓。

## 适用边界

实时预览与导出壁纸使用同一 DOM 渲染器。缩略图为 Canvas 捕获，对复杂背景滤镜、任意 CSS 变换、重复渐变与复合阴影仍可能近似。字体与视频已在当前 Windows Chromium 验证；**本轮未进行 Wallpaper Engine 实机导入、WE 内字体/视频解码或真实音频验证**。150 种组合的自动断言不等于每种数据内容与任意 CSS 均经过人工设计评审；过大字号、过小容器仍需按作品构图调整。
