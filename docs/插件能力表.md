## 设备能力与测试边界

- 浏览器 Battery API 仅作为 JSON 中显式 useBrowser=true 的可选降级，默认关闭；它不能可靠区分台式机与真实电池。
- 标准 Windows 电源接口不提供充满所需时间、电池健康或多电池独立信息，保持不可用，不填造估算。
- GPU/温度/风扇/进程/磁盘 IO 没有隐藏采集，也没有伪造示例读数。
- 本机网络流、HTTP/RSS/WS 测试值只证明协议与调度，不代表公网服务可用；真实天气和真实系统读数在报告中另有来源。
- 外部接口配置、网络策略、CORS、API 配额、播放器和驱动均会影响字段。失败保留最后成功值并标过期，或显示不可用。
- 已通过 30 秒真实采集和 100 次创建/销毁观察；未进行数小时浸泡、真实有电池硬件、WE 实机导入、真实媒体/频谱测试。
