## 性能测量的范围

环境：Windows Chromium 155，浏览器报告 16 个逻辑处理器，DPR 1.25；Node.js v24.19.0。CPU 型号查询被当前运行环境拒绝，因此不猜测具体型号。测试是浏览器端星空模板、请求 140 粒子，显示区域 960×540，每档约 1.6 秒。

最新记录：低/中/高实际程序绘制约 20.0 / 29.9 / 58.7 FPS，平均 JS 绘制函数耗时约 0.109 / 0.096 / 0.104ms；精确值以 JSON 为准。低档粒子密度为设定值的 45%，中档 75%，高档 100%。Canvas 单边限制 2048，实际最大 2048×1152。

此测量只包含 JS 绘制回调时间，不包含完整浏览器合成、GPU、视频解码、显存或系统占用，不能据此宣称“零占用”或目标机器长时间稳定。用户导入的大尺寸图片、视频和大量图层会改变成本。

## Wallpaper Engine 边界

实现前查阅官方网页壁纸、用户属性、音频、帧率、暂停与项目配置示例。`project.json` 对照官方公开字段结构进行本地校验，并检查入口、预览和属性类型。

**未执行 WE 实机导入、实际安装应用、真实系统音频、WE 内部字体/视频解码和长时间运行测试。** 模拟回调通过不等于实机通过。`examples/compatibility` 特意包含本地 TTF、VP9 WebM 和图片，供目标 Windows + WE 环境验证。实际导入步骤见 README 和各包内的导入说明。

## 已知限制

- 编辑器需要本地 HTTP 服务；导出壁纸可脱离服务运行。
- 媒体兼容性受目标 Chromium/WE 与编码支持限制，MP4 不作为网页视频导入格式。
- 图片裁切目前提供居中铺满/完整显示，没有自由焦点；组合为平面组，不支持嵌套。
- 缩略图已保留透明、轮廓和真实图表；复杂 CSS 滤镜、背景模糊、任意变换和复合阴影仍可能与完整场景略有区别；实际预览与导出共享完整渲染器。
- 时钟/日期依赖系统时间及系统语言环境，未打包的系统字体可能回退。
- ZIP32 与内存打包有体积上限，尚无流式大视频导出；场景和工程为 v2，支持迁移 v1，拒绝未知版本。
- 本机缓存、个人模板依赖同一浏览器来源。必须使用工程 ZIP 进行可靠备份和迁移。
- 系统源需要目标机器自己的伴随服务和令牌。此机无电池，有电池设备的电量/充电/续航尚未验证；部分硬件/驱动字段可能缺失。
- AQI、世界时区穷举、完整番茄钟时段、公网 RSS/HTTP/WebSocket 提供商没有全部实测。媒体/封面/进度和真实音频仅有官方接口实现及模拟回调验证；GPU、温度等规划项不伪装可用。
