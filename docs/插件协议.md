# 信息插件协议 v1 / 场景 v2

JSON 只描述配置，不执行脚本。运行时没有 `eval`、`Function` 或从插件 JSON 导入 JavaScript 的路径。旧场景 v1 由 `Scene.validate` 保留原图层/资源并迁移到 v2；未知版本拒绝。可编辑包标识也升级为 v2，导入支持 v1/v2。

## 文件与模块

| 文件 | 责任 |
| --- | --- |
| `js/info-model.js` | 内置注册表、声明式定义、配置 Schema、来源依赖、路径/规则、凭据清理 |
| `js/info-runtime.js` | 数据提供者、共享订阅、缓存/历史、超时取消、失败退避、派生计算 |
| `js/info-view.js` | 与来源无关的通用 DOM/SVG 展示、Shadow DOM、规则、映射与动画 |
| `js/info-css.js` | CSS 诊断、受控资源 URL、补全和示例 |
| `js/code-editor.js` / `info-editor.js` | 离线代码编辑器、插件目录、数据与外观可视化面板 |
| `companion/` | 可选的本机指标采样、令牌认证和固定资源代理 |

完整配置示例在 `examples/info-demo/scene.json` 和 `examples/info-live/scene.json`。Schema 在 `schemas/scene-v2.json`、`plugin-v1.json` 和 `source-config-schemas.json`。编辑器使用相同模型校验；除了 Schema，还检查跨对象引用、循环关联、时区、URL、素材和 CSS。不是完整通用 JSON Schema 引擎，只实现本协议使用的 type/enum/required/properties/additionalProperties/范围/数组/anyOf/本地 $ref。

场景主要字段：`format/version/id/name/width/height/fit/quality/background/effects/nodes/assets/sources/pluginDefinitions/stylePresets/themeVariables/customCSS/extensions`。根字段和图层字段也检查未知项，扩展数据应放入显式 `extensions` 命名空间。源和插件未知字段不被默默丢弃。

## 外观扩展（兼容旧场景 v2）

新增字段由 `InfoModel.normalizeAppearance` 补默认，未知字段仍报错。`appearance.backgroundOpacity` 只控制底板；`node.opacity` 控制整个图层。`shape` 为 `rect/rounded/ellipse/capsule`；`radiusX/radiusY` 可为 null，按统一圆角/全局主题继承。透明背景用 `transparent`，空背景会规范为透明，空渐变保留为空。

```json
{
  "background": "transparent", "backgroundOpacity": 0, "gradient": "",
  "shape": "ellipse", "radiusX": null, "radiusY": null,
  "borderStyle": "dashed", "borderWidth": 2, "borderColor": "#b7e4ce80",
  "shadow": 0, "shadowColor": "#00000044", "shadowX": -8, "shadowY": 12,
  "blur": 0, "trackColor": "#ffffff18", "trackOpacity": 0.6,
  "chartWidth": 12, "chartHeight": 22,
  "segmentCount": 20, "segmentGap": 6, "segmentRadius": 3,
  "segmentDirection": "horizontal", "segmentFill": "gradient",
  "animationDuration": 1800
}
```

这是 appearance 的局部片段，不是完整插件。分段只有 `plugin.view="segments"` 时生效；预设应用由 `InfoModel.applyAppearancePreset` 完整替换外观，并按元数据选择语义展示，不把名称、内边距等预设元数据写进 appearance。个人样式 JSON 可带 `view`，旧文件不带时保留当前展示。原生 shape 图层的 `fillOpacity` 单独控制填充。

## 数据源、实例与关联

```json
{
  "id": "system-main",
  "type": "system",
  "version": 1,
  "config": { "url": "http://127.0.0.1:18731", "adapter": "" },
  "interval": 2000,
  "staleAfter": 15000,
  "timeout": 8000,
  "historyLimit": 120
}
```

时长单位均为毫秒。源最多 100 个；历史 1–300 点、超时 500–30000ms。提供者会执行更严格的最短间隔：时钟/系统 1 秒、电池/本地文件 2 秒、HTTP 3 秒、状态 5 秒、RSS 60 秒、天气 5 分钟、空气质量 10 分钟。失败采用指数退避，并考虑 HTTP `Retry-After` 秒数；已存在数据保留最后成功时间，标为 `stale`。外部数据不在磁盘永久缓存，重开后重新采集；JSON 快照随工程保存且不因时间过期。

同类型、同配置的源通过稳定键共享 DataHub 条目，多个图层订阅一次采集。相同系统源的 CPU、内存、网络是同一批响应。不同网卡配置会产生不同传输订阅，但伴随服务本身仍每 2 秒只采样一次 OS。相同源 ID 的采集设置更改会重新绑定。隐藏图层释放订阅；如果它的源仍被可见的派生源依赖，则上游继续采集。最后一个订阅释放时取消请求、定时器或 WebSocket。WE 暂停事件停止采集并暂停动画，恢复立即刷新。

源状态：`loading / ready / stale / error / unavailable`；带 `data/updatedAt/lastAttempt/error/source`。缺失字段保持 null/undefined，不填造零值。每个提供者的 config 字段见 Schema；天气经纬度允许 null 表示未配置，但不允许字符串坐标。字段路径不允许 prototype、constructor、__proto__。

派生源只接受具名 `inputs` 和 `sum/average/difference/ratio/min/max`：

```json
{
  "inputs": {
    "used": { "sourceId": "system-main", "path": "memory.used" },
    "total": { "sourceId": "system-main", "path": "memory.total" }
  },
  "operation": "ratio"
}
```

输出字段为 `value`；可设置倍率 100、单位 `%`。关联按依赖顺序计算，循环/不存在的源拒绝，缺失输入或除零显示不可用，上游失效则派生结果也失效。

插件实例字段为 `definition/version/sourceId/field/view/options/appearance/rules/mappings/animations/css`。通用 options 包含标题、标签、单位、精度、换算倍率与偏移、范围、模板、图标、布局、间距、空值等；没有任意代码字段。

## 规则、映射、动画

```json
{
  "rules": [
    { "when": { "field": "cpu.percent", "op": "gte", "value": 80 }, "set": { "color": "#ff786e" } },
    { "when": { "field": "$state", "op": "eq", "value": "stale" }, "set": { "opacity": 0.4 } }
  ],
  "mappings": [
    { "field": "cpu.percent", "target": "fontSize", "min": 0, "max": 100, "outMin": 44, "outMax": 80 }
  ],
  "animations": [
    {
      "target": "icon", "duration": 1800, "delay": 0,
      "iterations": "infinite", "easing": "ease-in-out",
      "when": { "field": "charging", "op": "eq", "value": true },
      "keyframes": [ { "opacity": 1 }, { "opacity": 0.4 }, { "opacity": 1 } ]
    }
  ]
}
```

条件：`gt/gte/lt/lte/eq/ne/exists/empty/truthy`，或嵌套 `all/any/not`。每个规则设置 `color/background/opacity/hidden/icon/animation`，依次应用，后者覆盖前者；动画快捷值 `none/pulse/glow`。例如媒体 `playing=false` 时 hidden=true、电池充电时图标变闪电并 pulse。状态样式也可以用 `.muyu-card[data-state="unavailable"]` 写 CSS。

映射输入线性钳制到 min–max，再映射到 `opacity/fontSize/radius/blur`；每实例最多 20 个。动画目标只允许 `card/value/icon`，关键帧只允许 `opacity/transform/color/backgroundColor/offset`，持续 100ms–10 分钟，最多 20 帧、10 个动画。禁止脚本目标和事件字符串。全局 speed 调整插件动画 playbackRate，0 停止动画。JSON 中 `effects` 可配置粒子 type/count/speed/strength/color/size；节点 `parallax` 控制鼠标视差。

## 注册与扩展边界

内置定义注册在 `InfoModel.defs`，声明 ID、版本、说明、字段与单位、所需能力、通用配置 Schema/默认值、展示方式、样式接口、生命周期和导出文件。新增内置声明或已有提供者上的用户插件无需修改编辑器交互核心。

用户声明式插件通过目录“导入插件”导入，ID 必须 `user.*`、版本为 semver，选择已有 provider/view，配置标准功能默认值、字段和样式；示例 `examples/user-progress.plugin.json`。接入已有提供者不会获得新增系统权限。导入后的定义随工程保存；“导出插件配置”同时包含所需声明定义与源配置，可在其他工程重新添加。声明式定义使用共享的生命周期、渲染代码与受限样式接口，不允许自带 lifecycle 函数或 exportFiles 路径。

代码扩展目前**不开放导入**。新增数据提供者或渲染器需要可信开发者修改本地源代码、审核并重新验证；JSON 不能授予命令、任意文件或 JS 执行权限。单个实例渲染异常显示“插件错误，可在属性中恢复”，不终止其余图层。代码运行时错误与缺失数据能力分开处理。

## 本机服务协议

监听回环地址；Host 检查防止 DNS rebinding，Origin 白名单和 Bearer token 验证保护跨网页访问。固定接口：

| 接口 | 行为 |
| --- | --- |
| GET `/v1/status` | 版本、能力和采样时间，不回传令牌 |
| GET `/v1/metrics` | CPU / 内存 / 网卡 / 电池 / 磁盘 / uptime 批量快照 |
| GET `/v1/files/<name.json>` | 仅固定 data 目录、文件名检查、JSON 和 1MB 逻辑上限 |
| GET `/v1/proxy/<id>` | 仅私密配置中的固定 URL 与鉴权头，8 秒超时，无重定向 |
| POST `/v1/shutdown` | 经同样认证停止本服务，不执行通用命令 |

`POST /__muyu_companion/connect` 属于编辑器服务，必须同源并携带 `X-Muyu-Action: connect`，用于用户点击后的本机连接。不会在静态目录公开 `.runtime`。响应与指标禁用缓存。WebSocket 数据由浏览器直接连接，不通过本机代理。

导出依赖检查包括派生上游；私密 token、API key、Authorization/Cookie 等字段清除。工程只保存代理 ID，分享者必须另行向接收者说明固定代理配置。浏览器直连不绕过鉴权、CORS 或安全策略。
