# 信息插件使用说明

双击项目根目录的 `一键打开.bat`。左侧选择“信息插件”，搜索所需信息，点“添加”。“示例信息桌面”会放入八个可编辑组件，覆盖前的作品可撤销恢复。首次使用系统指标，点“连接本地服务”；无需管理员权限、账号或安装依赖，也不会配置开机启动。

目录共 49 项：17 项可用、15 项需本地服务、7 项需配置、10 项规划中。状态表示运行条件，并不表示每种设备或外部接口都已经实机验证。逐项来源、限制和测试范围见 [插件能力表](插件能力表.md)。

## 从信息到外观

每个信息图层分成四部分，互相独立：

| 部分 | 位置 / 含义 |
| --- | --- |
| 数据源 | `scene.sources`，负责时钟、系统、天气、JSON 等采集 |
| 功能 | `node.plugin.field/options`，选择字段、单位、换算、精度和空值处理 |
| 外观 | `node.plugin.appearance/css/rules`，字体、配色、排版、状态与局部覆盖 |
| 展示组件 | `node.plugin.view`，数字、文本、图标、进度、环形、仪表、折线、柱状、列表、表格、月历、模拟时钟、液体、分段、条件容器 |

选中 CPU 图层，在右侧“展示组件”切换数字、进度、仪表盘或折线。切换保留数据绑定和样式。“绑定数据源”可选择已有源，重复图层也继续使用同一源；CPU、内存和网速默认共享批量 `system` 采集。

通用字段路径支持 `memory.percent`、`network.interfaces[0].name`。对于已声明字段，可直接用下拉选择；切换到内存字节或网速字节字段时，会设置 GiB / MiB/s 的换算。手动输入其他字段时，请同时设置单位和倍率。无效或缺失值使用“空值占位”，不伪造为 0。

基本外观直接可见，其他字体、间距、边框和状态参数折叠在“更多…”中。主题色、字体和圆角在取消选择后的全局属性中设置。局部圆角为空、字体为空及颜色为 CSS 变量时继承主题。“恢复主题继承”会恢复这些关联。

十种外观预设与数据独立。“保存此样式”将展示组件、字体、配色、排版和 CSS 保存为本机个人样式，同时下载 JSON 备份。“导入样式文件”可以跨工程使用；“导出/导入主题预设”处理全局变量与全局 CSS。

具体的透明背景、椭圆/胶囊、边框阴影、图表细节与预设切换操作见 [样式自定义与复核](样式复核与使用.md)。背景透明度独立于内容；预设会清除上一外观残留，四个语义预设自动选择对应图表，保存样式也保留该展示。

## 真实数据与可选伴随服务

普通浏览器不能读取完整硬件指标，Wallpaper Engine 也没有 CPU、内存等通用硬件接口。本项目的可选 Node + Windows PowerShell 服务仅在回环地址 `127.0.0.1:18731` 提供只读数据。

1. 在插件目录或系统插件属性中点“启动并连接本地服务”。也可双击 `启用系统信息.bat` 启动后再在界面连接。
2. CPU、内存、网卡速率、累计流量、启动时长和固定磁盘容量来自真实系统接口，2 秒批量采样。网速启动后需等待两次采样。
3. 电池使用 Windows `GetSystemPowerStatus`。本次测试设备报告“没有系统电池”，电量、充电和续航显示不可用；AC 电源状态仍可单独绑定。不使用浏览器常见的默认 100% 冒充系统电池。
4. 双击 `停止系统信息.bat` 可停止服务；也可在“连接 / WE 令牌”断开编辑器连接。断开编辑器不会结束其他壁纸正在使用的服务。

服务的 CPU 占用基于系统 CPU 时间差；频率是 OS 报告的各核 MHz 平均值，可能不是实时睿频。内存统计是 OS 可用内存口径。网速是所选活动网卡的计数差，累计流量是网卡自身计数，不是应用自行记账的“本月流量”。自动选择尽量排除常见虚拟网卡，复杂 VPN / 多网卡环境请手动选择。磁盘提供容量，不提供读写速率。

服务仅接受令牌和许可来源，不提供任意执行命令或任意路径读取，不申请管理员权限或自动开机启动。令牌保存在 `.runtime/companion.json`，编辑器的私密连接保存在 IndexedDB settings 中，两者均不打包。不要公开分享 `.runtime`。更换令牌或端口后需重启服务并重新连接。

如使用其他编辑器端口，将其本机来源加入私密配置 `origins` 后重启伴随服务；默认允许 4173，以及携带令牌的本地文件来源 `null`，用于 WE。认证没有因为本地文件来源而关闭。

## 天气、媒体和外部信息

天气使用 [Open-Meteo Forecast API](https://open-meteo.com/en/docs)，空气质量使用其 [Air Quality API](https://open-meteo.com/en/docs/air-quality-api)。填写纬度/经度即可获取；也可搜索城市。使用多个城市时搜索并添加，再通过“切换城市”选择。只在用户点击定位按钮后请求浏览器定位权限。

天气可绑定温度、体感、高低温、湿度、风向/速、降水概率、日出日落、UV、多日及逐小时预报。多日字段搭配表格、逐小时字段搭配列表或柱状图。支持摄氏/华氏；保留数据署名。公共端点有使用条件和限流，本项目面向本地非商业制作，不包含商业 API 授权。真实外部数据并非离线依赖。

媒体使用 [Wallpaper Engine 官方媒体监听](https://docs.wallpaperengine.io/en/web/audio/media.html)，接收 Windows 全局媒体会话的曲名、歌手、专辑封面、播放状态和可选进度。部分播放器不提供进度/封面；普通浏览器明确显示接口不可用。没有播放控制或歌词接口。频谱使用原有“音频频谱”组件，WE 中为真实 128 频段，编辑器中明确标注模拟；时域波形属于规划项。

JSON 快照完全本地，可在“编辑 JSON 数据 / 待办”中更改对象或数组。`todo` 为本地列表，待办勾选状态通过 JSON 的 `done` 编辑；尚无任务提醒、日历订阅或账号同步。番茄钟可以开始 / 重置 25 分钟，按时间戳计算，不通过累加计时器推算。

HTTP JSON、WebSocket 和 RSS 需要自己配置有效地址。浏览器直连遵守 CORS；错误、限流和离线会显示，绝不把 `no-cors` 不透明响应当作成功。服务状态通过 HEAD 检查，必须是允许跨域的端点；CORS 失败不能推断服务器已离线。

私密 API 使用固定本机代理。在 `.runtime/companion.json` 的 `proxies` 添加配置后，源中勾选“通过本机凭据代理”，填写代理 ID：

```json
{
  "proxies": {
    "my-status": {
      "url": "https://your-api.example/status",
      "headers": { "Authorization": "Bearer YOUR_PRIVATE_KEY" }
    }
  }
}
```

这是修改现有私密配置的片段，保留其 token、port、origins。URL 由本机操作人固定配置，网页不能传入任意代理目标；代理不跟随重定向。密钥不要放入场景、URL 查询或 CSS。

本地动态 JSON 只能读取 `companion/data/` 中的 `.json`，例如“示例.json”；更新文件后组件按间隔重读。任意目录读取、文件写入和命令执行均不提供。

## CSS 和 JSON 联合设计

选中 CPU → 右侧添加“超过 80 变红” → 选择仪表盘 → 打开“局部 CSS 编辑器”，输入：

```css
.muyu-value {
  font-family: Consolas, monospace;
  text-shadow: 0 0 18px currentColor;
}
.muyu-title::before { content: "CPU · "; }
```

数字字体与光晕由 CSS 决定，颜色仍随 JSON 阈值变化，可视化字号和仪表形状继续生效。保存、刷新、工程重开和导出使用相同协议与渲染器。离线示例 `examples/info-demo` 用明确标注的 JSON 值 85% 验证该组合；`examples/info-live` 使用真实系统源。

代码工作区支持高亮、基础字段/属性补全（Ctrl+Space）、撤销重做、导入导出、复制、错误路径和恢复有效版本。CSS 有效修改立即显示在右侧真实数据快照中；点击“确认应用”才写入项目。JSON 先“预览修改”，再确认。切换可视化设置后重新打开代码工作区会读取最新数据；未知字段和不兼容版本会报错，不能静默覆盖正常项目。

CSS 顺序：内置样式 → 可视化变量 → 全局 CSS → 局部 CSS，最终仍遵循浏览器的选择器优先级、继承及 `!important`。条件规则和映射使用卡片内联属性，因此普通样式表不会覆盖其状态颜色；可自行使用 `!important` 明确覆盖。推荐让 CSS 定义字体/装饰、规则定义状态颜色。

整个壁纸在 Shadow DOM 中，各插件也有独立 Shadow DOM。全局 CSS 同时注入壁纸和插件，局部 CSS 只注入该插件。绘制包含边界阻止 `position:fixed` 越出画布或插件图层。插件 CSS 不能用选择器穿透到其他插件或编辑器。关键帧、伪元素、媒体查询可用；媒体查询参照运行窗口视口，窄画布预览不等于独立浏览器窗口的媒体尺寸。

稳定接口：`:host`、`.wallpaper-stage`、`.wallpaper-node`（全局）；`.muyu-card`、`.muyu-title`、`.muyu-value`、`.muyu-unit`、`.muyu-label`、`.muyu-icon`、`.muyu-status`、`.muyu-chart`、`.muyu-row`（插件）。变量包括 `--muyu-accent`、`--muyu-font`、`--muyu-radius`、`--muyu-background`、`--muyu-foreground`。CSS 局部错误不会影响编辑器。

图片/字体先导入素材，再写 `url(muyu-asset:素材ID)`。导出收集这些引用，解析为相对路径；缺失资源阻止导出。禁止 CSS `@import`、外部或绝对路径 URL、脚本样式。字体可直接在插件属性中选择打包字体，无需自己写 `@font-face`。提供关键帧、媒体查询和变量示例，点击“插入示例”可使用。

## 桌面未连接时

壁纸显示 —% 或“需连接本地伴随服务”，双击 `连接桌面系统信息.bat`，启动并复制连接码，粘贴到 Wallpaper Engine 当前壁纸右侧的“本机信息服务令牌 / 本机系统信息连接码”。已有令牌输入项时不必重新导入。编辑器的私密连接不随导出传入 WE。详见 [桌面信息连接说明](桌面信息连接说明.md)。

## 导出与接收

工程、壁纸、插件配置、样式及主题可分别导出。工程/壁纸导出会清除常见凭据字段与鉴权头；接收者须重新配置。不要将敏感业务数据作为普通文本/JSON 分享，程序无法辨认任意字段里的秘密。

导出对话框列出离线、联网、本地服务、媒体接口及未配置依赖，关联计算的上游依赖也会列入。ZIP 包含 `scene.json`、内嵌 `scene-data.js`、共享插件运行代码、`插件依赖.json`、相对资源、官方格式 `project.json` 和预览图，不含编辑器与私密设置。

WE 导入：完整解压 → 打开 Wallpaper Engine 编辑器 → 将 `index.html` 拖到“创建壁纸” → 保存并应用。ZIP 下载并不等于安装壁纸。系统插件在目标机器启动本地服务，再从“连接 / WE 令牌”复制该机器令牌，填写 WE 壁纸属性“本机信息服务令牌”。普通浏览器独立页面没有此属性界面，系统插件显示未连接；时钟、JSON 和其他组件仍正常运行。
