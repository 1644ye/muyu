# 插件样式渲染审计

本次修复针对“透明背景仍有底板、不能设置椭圆、分段预设没有分段效果”等实际问题。编辑器与导出继续共用 `js/info-view.js`，测试页使用相同代码，没有另写视觉演示。

## 可直接复核

- 打开 `http://127.0.0.1:4173/tests/style-view.html`，点击“运行全部样式检查”。
- 最终浏览器结果：`style-view-results.json`，18 项通过，0 项失败。环境为 Windows、Chromium 155、设备像素比 1.25。
- `style-gallery.png` 包含 9 个代表控件和全部 10 种真实预设的浏览器截图。
- 18 项中包含 **15 种展示 × 10 种外观，共 150 个实际 DOM 组合**；每个组合检查有效数据、布局尺寸、CSS 诊断、预设标识和 SVG 非法数值。

150 个组合是实际 DOM 与计算样式检查。视觉人工核对覆盖截图中的 9 个代表案例和 10 个预设，没有将其称为逐一人工观察全部 150 个组合。

## 已纠正的行为

| 范围 | 实际行为与证据 |
| --- | --- |
| 完全透明 | 底板透明度独立于文字和图表；透明底色与透明度 0 均禁用残留背景模糊。阴影为 0 时真正为 `none`，不再保留向下偏移的实心黑影。 |
| 椭圆、胶囊、直角、圆角 | 设置真实边界与裁切，支持独立横纵圆角；椭圆增加安全内边距。 |
| 分段 | 真实独立 DOM 段，支持数量、间隙、圆角、横纵、渐变；完整段数为 `floor(百分比 × 段数 / 100)`。0% 无亮段，100% 全亮，激活色不会被轨道盖住。 |
| 环形与仪表 | 使用真实 SVG 进度、轨道与指针；线宽接受 1–100。仪表值置于指针下方，字号不再限制为 64px。 |
| 液体 | 真实液面高度与波浪，轨道颜色、边框粗细、容器圆角和波动周期可调。 |
| 轨道与柱形 | 独立轨道颜色及透明度、进度条高度；柱形正确处理负值和空值，图表不生成 NaN 或负高度。 |
| 像素 | 原创字体直接内嵌于共用运行代码；真正使用网格数字字形。仅数字与冒号使用像素字体，小数点、负号、百分号、字母及中文正常回退。自定义字体可覆盖。 |
| 霓虹 / 终端 | 霓虹具有实际发光，终端具有等宽字体及提示符；应用预设时不残留前一预设的模糊、渐变、字体和发光。 |
| CSS | 局部和全局仍按原先顺序覆盖；底板可用 `.muyu-card::before` 或 `--muyu-card-bg` 控制，直接给 `.muyu-card` 设置背景也能覆盖底板。插件的 Shadow DOM 保持隔离。 |
| 四种布局 | 纵向上下排；横向数值与进度并排且图表保留高度；紧凑减少留白及辅助信息尺寸；展开增加纵排居中标题和分隔底栏。 |
| 缺数据 | 未连接服务、加载中和不支持字段保留真实原因，即使关闭更新时间也有明确原因；只对非空但类型错误的数据建议更换展示。 |
| 动画生命周期 | 100 次数据变化保留 DOM 与动画实例；暂停、恢复、关闭覆盖卡片、子元素及全部 before/after 伪元素。已结束的单次动画不会被下一次数据更新重新启动；删除后取消动画。 |

## 验证界限

- 字号、间隔、段数与图表尺寸保留用户控制；极小的组件配极大的字号仍可能被组件边界裁切，应调整尺寸或留白。没有使用隐藏的 64px 上限覆盖用户设置。
- 像素样式是数字像素字体，未声称具备完整中文字库。
- 复杂自定义 CSS 的导出壁纸仍由浏览器真实渲染；缩略图对复杂滤镜、背景模糊和任意 CSS 变换的近似情况见导出审计说明。
- 这些是浏览器和导出结构验证，不代表 Wallpaper Engine 实机测试；本轮也未进行数小时持续运行测试。
